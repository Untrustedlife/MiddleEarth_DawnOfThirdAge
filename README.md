#Middle-earth

This Repo contains the latest prepared Middle-earth world for Pilgrimage, complete with a pre-generated history inspired by Tolkien's legendarium.

This world starts at the dawn of the Third Age, a period that isn't explored all that much in Tolkien's stories, 
leaving plenty of room for the simulation to take things in interesting directions. 
It also has a couple fictional characters too, made by me, just to flesh it out.

#Use the Prepared World

-Locate your Pilgrimage world's save blocks folder.

-Copy the included MiddleEarth_DawnOfThirdAge.block file into that folder.

-If a file with the same name already exists, back it up before replacing it.

-Launch Pilgrimage and load the Middle-earth world.

#A Few Notes
This is a starting point, not a static recreation of Tolkien's world. Once the simulation begins, history will take some very unexpected turns becaus ethe simulation is not 
fully developed at this time.

Your version of Middle-earth will develop its own stories, conflicts, and alternate histories.

If you want to preserve the original world, consider duplicating it using Pilgrimage's **Mitosis** feature before experimenting.

The world also has kinda shitty ASCII art for the creatures. This was created as an experiment, and I would welcome anyone to update and flesh it out!

This was originally made for 0.3.5, but the save has been updated for the current 0.3.6 development version of Pilgrimage. The schemas might still change before 0.3.6 releases.

There are some protections in-game for broken worlds, but I may not have caught all edge cases, and it doesn't validate the schema much.

The souls and the One Ring are set up for the newer possession mechanics. The Ring's behavior is tied to its bearer as a parasitic soul, rather than a regular inventory item.
